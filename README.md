# Пределы Галактики

Браузерный прототип тактической настольной стратегии «Пределы Галактики» для двух игроков на одном экране (hot-seat).

**Играть:** https://svc311.github.io/predelgalactiki/

## Что есть
- Гексовое поле из 7 секторов, три расы: Дорги, Ксарионы, Велары.
- Экономика: шахты, фабрики, башни; пять классов отрядов.
- Случайная местность (скалы, вода, лес, пески, руины, радиация) и дороги.
- Галочки «Баланс для плейтеста» в окне новой партии.
- Звуки и часть арта сгенерированы в Creative Claw.

## Запуск локально
Откройте `index.html` в браузере или запустите любой статический сервер в папке репозитория, например `python3 -m http.server`.

Сохранение партии хранится в браузере (localStorage).
